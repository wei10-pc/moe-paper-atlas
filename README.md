# Vision MoE Paper Atlas

A static literature atlas for computer-vision Mixture-of-Experts, routing, gating, and expert-system papers.

## Data

The data bundle is generated by `scripts/build_paper_data.py` from:

- `choucisan/CVpaper`: CVPR, ICCV, ECCV paper metadata.
- arXiv cs.CV API: CV-only keyword expansion.
- OpenAlex: conservative CV-filtered strict MoE expansion.

Generated files:

- `data/papers.json`
- `data/summary.json`

## Run Locally

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Refresh Data

```bash
python scripts/build_paper_data.py
```
